# 人生シミュレータ：20〜30歳プロトタイプ

## 起動

`index.html` をブラウザで開くだけです。ネットワーク・サーバー・外部ライブラリは不要です。`sim.js` は同じフォルダに置いてください。

## 遊び方

1. 20歳から開始します。初期設定は「新しい人生」から名前と職業（`student` / `parttime` / `fulltime`）を指定できます。
2. 「次のイベントまで進む」で時間を進め、選択肢を選びます。
3. 結果画面で即時の変化を確認し、「結果を確認して続ける」で再開します。
4. 未来の出来事には過去の選択が原因として表示されることがあります。「人生の履歴」「人生の転機」も確認してください。
5. 30歳になったら終了します。自動セーブはブラウザ内に保存されます。JSON形式の書出し・読込みも可能です。

## 実装した機能

- 20歳〜30歳の月単位進行、約20種類のイベントと複数の選択肢
- 学生・就職活動・アルバイト・正社員・転職・独立・恋愛・療養・学びなどの並行シナリオ
- 8つの可視パラメータ、職業・収入・資産・ストレス・恋人・居住地、友人関係
- 選択後の状態差分、シナリオ開始・終了、Influenceによる抽選重み変更、Consequenceによる将来イベント予約
- 過去の選択から派生したイベントへの因果リンク、転機・履歴表示
- シード付き乱数、選択のコピー上での状態変更、自動セーブ・JSONエクスポート/インポート

## 今回の実装範囲と制約

これは既存仕様書を基にした **20〜30歳向けの動作する縦断プロトタイプ** です。仕様書の全機能を実装した完成版ではありません。

- イベント定義は独立JSONではなく `sim.js` 内の宣言的オブジェクトに集約しています。
- 一般イベントにも選択肢があるため、すべてのイベントで停止します（完全自動進行は未実装）。
- 結果分岐は選択肢ごとに固定。結果自体の確率分岐、人物複数管理、性格・性に関する細かなシミュレーションは未実装です。
- Consequenceは `once` 方針のみで、最初の適格月に一度抽選します。
- 乱数再現はゲーム状態からの再開に対応。乱数をイベント別ストリームには分離していません。
- 月収・資産はゲーム内の抽象単位です。数値はバランス調整前です。
- 保存スキーマの旧版互換はありません。形式が違うセーブは読み込みません。

## 簡易テスト

ブラウザの開発者ツール（Console）で `LifeSim.runTests()` を実行すると、正社員登用、シナリオ遷移、状態の不変更新、予約、復元可能性、乱数シードの基本検証を行います。
